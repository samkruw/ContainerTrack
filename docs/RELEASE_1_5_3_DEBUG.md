# Container Track 1.5.3 – Debug-Testversion

Die APK steht unter **Assets → ContainerTrack-1.5.3-debug.apk**; die separate `.sha256`-Datei enthält ihre Prüfsumme.

- Quick und Zusatzarbeiten werden bei Lieferung und Return nicht mehr abgefragt oder angezeigt.
- Vorbereitete E-Mails und neue ZIP-Exporte enthalten diese Angaben nicht mehr, auch bei älteren Aufträgen.
- Die Export-TXT hat jetzt sechs Spalten statt acht; META verwendet schemaVersion 5.
- Der Return-Fotoablauf einschließlich „Sauberfotos überspringen“ und der 24h-Erinnerung bleibt erhalten.

**Geräte- und visuelle Abnahme bleiben offen.** Diese Version ist ein Debug-Build. Ein Update über eine bereits installierte APK setzt dasselbe Signaturzertifikat voraus. GitHub-Debug-Builds können einen anderen Schlüssel verwenden; eine Deinstallation löscht lokale Aufträge und Fotos.
