ContainerTrack V8 PWA

GitHub Pages speichert KEINE Container-Daten und KEINE Fotos.

Gespeichert wird lokal im Browser:
- Container-Nummer
- CX-Nummer
- Fotos
- Verläufe

Technik:
- IndexedDB = lokale Datenbank auf dem Gerät
- GitHub Pages = nur Hosting der statischen App-Dateien
- Service Worker = cached nur App-Dateien für PWA/Offline-Nutzung

Installation:
1. Alle Dateien aus diesem Ordner ins GitHub-Pages-Repository hochladen.
2. GitHub Pages aktivieren.
3. HTTPS-Seite auf Android in Chrome öffnen.
4. "Installieren" drücken oder Browser-Menü > "App installieren".
